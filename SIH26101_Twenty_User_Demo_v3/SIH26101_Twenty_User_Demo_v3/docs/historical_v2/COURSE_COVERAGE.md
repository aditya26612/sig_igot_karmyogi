# Course coverage and remaining catalogue work

All 18 competencies currently lack production-validated course alignment. No official course syllabus or learning outcome set was verified in this build. That is a different question from whether a real course URL exists.

In DEMO mode, Digital Tools has one documentary-linked course with simulated mapping approval: Microsoft Excel Advanced, proposed L2 -> L3. Statistical Data Management has Responsible Data Management, proposed L2 -> L3. The latter is only a bridge toward an L4 target. These are supporting hypotheses to test integration, not published provider promises.

The other 16 competencies have no eligible recommendation under the strict policy: Sampling Methodology; Critical Thinking; Survey Data Collection; Communication; Sampling Frames and UFS; Geospatial Tools; Industrial Statistics; Statistical Analysis; Price Statistics; Statistical Computing; National Accounts; Data Privacy and Disclosure Control; Metadata and Dissemination; Leadership; Collaboration; Strategic Thinking.

Some have real-course title candidates, but unresolved destinations or pending mappings still block recommendation. The cybersecurity links are documented, but cybersecurity is not equivalent to advanced statistical disclosure control. The current fictional blueprints are intentionally excluded from recommendations.

Next catalogue actions are bounded, not another open-ended research exercise: resolve the five MoSPI course destinations through an authorized catalogue view; inspect real syllabuses; collect published learning outcomes where available; have a real trainer approve competency/level mappings; and retest learner destinations with an authorized account. Never ask users to share credentials or scrape protected course content.

Basics of Communication has an official-source link association in the source register, but remains null in the course table because Master Prompt v2 explicitly requested null for that row. Changing this requires a reviewed catalogue update, not an invented URL.

See `course_coverage.csv` for machine-readable per-competency status, and `sources` for the supporting publications.
